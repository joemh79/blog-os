欢迎来到 Blog-OS——一个为"搭得快、看得顺、用得久"而设计的个人博客系统。

## 它是什么

- **前台**：纯 HTML / CSS / JS，零构建，直接丢到 Cloudflare Pages 就能跑
- **后台**：Cloudflare Worker + D1，写文章、改设置、管留言，全在浏览器里完成
- **免费**：整套架构跑在 Cloudflare 免费额度内

## 从哪里开始

1. 去 `/admin/` 登录管理后台
2. 写第一篇文章，点"发布"
3. 回到首页看看效果

这篇欢迎文章就是用后台 Markdown 编辑器写出来的，你也可以随时编辑或删除它。
